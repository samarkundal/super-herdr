# Changelog

## [0.1.0] - 2026-11-24

### New
- Project rail: a Slack-style column of permanent projects, with dots for agents waiting on you and agents at work.
- Permanent projects: they outlive Herdr spaces and reopen in their folder.
- New tabs (+, Cmd+T, tab menu) open in the project's folder.
- Waiting on you: every blocked or finished agent across projects, at the top of the sidebar.
- Sidebar tabs: this project's agents, Explorer, and Herdr's original lists.
- Explorer for the project's folder, with git status marks.
- File viewer with a Source / Preview switch for Markdown.
- Super Herdr header and logo.
- `scripts/install.sh` to install and update.
